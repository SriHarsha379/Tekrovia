# TekRovia — What We Need From You

Hi! The platform is fully built and ready to demo.
To go live, we need the following from your side.
Each item is independent — share as and when you have it,
we will integrate immediately.

---

## 🔴 Critical (Platform cannot go live without these)

### 1. OTP / Login (Most Urgent)
Students cannot log in on the live site without this.

- Sign up at **msg91.com**
- Register a Sender ID (e.g. TKRVIA) — takes 3-7 days TRAI approval
- Share: API Key + Sender ID

**OR** use email OTP via **resend.com** (faster, same day)

---

### 2. Domain Name
- Register **tekrovia.com** (or preferred domain)
- Share DNS access so we can point it to the platform

---

### 3. Hosting
We recommend:
- **Vercel** — for the website (free to start)
- **Railway.app** — for the backend + database (~₹3,000/month)

Create accounts and share access, or we can set it up for you.

---

## 🟡 Important (Needed for full functionality)

### 4. Razorpay — Online Payments
Students pay online, platform auto-enrolls them.

- Sign up at **razorpay.com** with business PAN + bank account
- KYC takes 1-3 business days
- Share: Key ID + Key Secret

---

### 5. OpenAI API Key — AI Features
Powers: AI career roadmap, mock interview questions, resume review, doubt assistant.

- Sign up at **platform.openai.com**
- Add billing (pay per use — est. ₹500-2,000/month at launch)
- Share: API Key

---

### 6. Email — Transactional
For: welcome emails, invoices, OTP backup, notifications.

- Sign up at **resend.com** (free tier available)
- Verify your domain (we will guide you)
- Share: API Key + sending email (e.g. noreply@tekrovia.com)

---

## 🟢 When Ready (Can launch without these initially)

### 7. WhatsApp Business — Automation
For: registration confirmations, session reminders, payment links, onboarding messages.

- Sign up at **wati.io** or **interakt.shop**
- Connect a dedicated WhatsApp Business number
- Share: API Key + Endpoint URL
- Note: Meta template approval takes 3-7 days per message

---

### 8. Video Hosting — Course Videos
For: protected video delivery for course lessons.

Option A (Simple): Paste YouTube/Vimeo/Loom links per lesson — works today, no setup needed.

Option B (Secure): AWS S3 + CloudFront for protected video.
- Create AWS account
- Share: S3 bucket name + CloudFront URL + Access keys
